Page hero backgrounds. Replace a file (keep the same name) to change that page's background:

  progression.webp   -> Skills & Levelling page
  rules.webp         -> Rules of Engagement page
  faction-tiers.webp -> Faction Tiers page

Each starts as a copy of the original home-page art (placeholder).
Wide images work best (about 1600x800). To use a different file type or name,
edit src/data/pageBackgrounds.ts.
